# People Relationship Manager

An experimental personal relationship workspace built around structured data and [Mech](https://github.com/mech-lang/mech).

## Project status

Development currently takes place privately. This public repository intentionally contains only this README. Reviewed source code and fictional demonstration data will be published here when a working release is ready.

## Project direction

- Organize people, attributes, interactions, and connections.
- Explore a graph-based interface for understanding relationships.
- Use explicit data rules to produce understandable views and follow-up suggestions.
- Keep personal working data separate from distributable examples.

## Demonstration data

Future public examples will use fictional people only. This repository does not include a contact database or application source code at this stage.
